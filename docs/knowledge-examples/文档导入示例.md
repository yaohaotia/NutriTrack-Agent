# RAG 导入演示（功能样例）

本文档只用于演示文档导入、检索、引用和更新，不是营养指南。

## 检查口令
本演示文档的检查口令是 NUTRI-RAG-2026。可以向健康助手询问“我导入的文档中的检查口令是什么”，检查它是否实际检索了这份资料。

## 使用步骤
先进入营养知识库，导入本文件。在检索试验台输入“检查口令”，比较关键词、向量和混合检索结果。点击“定位这个文段”查看提取的原文，再进入健康 Agent 提问。回答后的来源卡片应能跳回这份文档。

## 更新实验
复制本文件并修改检查口令，使用知识库的更新按钮替换文档。版本号会增加，搜索应返回新内容。旧回答引用跳转到更新后的资料时，会提示版本变化。删除文档后，它应从检索结果中消失。
